# 运维与排障

网页 **运行** 页可以看到每次任务的步骤、token、估算费用和错误类型。不要在失败时盲目点「立即运行」连点多次——写作步骤会再次消耗输出 token。

## 常见问题

**任务显示 failed，日志是 LLM 401**  
Key 无效或没填。检查 `.env` 的 `LLM_API_KEY` 或网页设置。不要对 401 自动重试。

**一篇都没写出来，但是运行成功**  
筛选分数都低于阈值，或候选与已有文章去重后为空。日报仍可能写下「没有足够重要的新信息」。降低最低分数，或等第二天。

**GitHub Star 精讲跳过**  
未填用户名、公开 Star 为空、或队列里没有 queued/retry。同步失败时不会把项目标成取消收藏，可从原队列继续。可在任务里填 `prefer_repo`，或灵感箱贴仓库 URL。

**企业微信没收到**  
网页仍有今日文章。检查 CorpID / Secret / AgentId、应用可见范围、markdown 是否开通。`PUBLIC_BASE_URL` 未填时推送里没有可点击链接。推送失败不会把整次任务标成失败。

**日报写了「尚未完成核验」**  
对应官方页无法访问、过短或像前端渲染。这不是「今天没有更新」。2C2G 不跑浏览器内核。

**磁盘涨得快**  
主要是 SQLite、文章正文和 `data/media` 里的官方原图。对话多了会变大。

**token 突然很高**  
看该次运行是否在高峰时段，或筛选是否误开了 thinking。代码里 triage / agentic_pick 写死关思考。

**网页能打开但保存任务/灵感会一直转圈**  
项目若在 OneDrive 里，SQLite 写入会被文件锁挂住。数据库应在本地磁盘；本机已自动改到 `%LOCALAPPDATA%\yandu\`。

## 手动重跑

任务卡片上的「立即运行」会从头走完整条 workflow。当前版本不支持从某一步续跑。Star 写作失败会把该仓库标成 `retry`，下次优先再试。

## 费用对照（Flash 低谷，约）

三条任务合计：筛选 + 1 篇日报 + 1 个 Star + 1 篇 Agentic，大约 **¥0.34–0.54 / 天**（按 1 美元 = 6.7 元折算）。账单大头是写作输出（含 thinking）。
